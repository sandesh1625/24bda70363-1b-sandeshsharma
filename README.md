AIM:-
To design and implement a basic full-stack web application using HTML, CSS, and JavaScript, where the frontend interacts with backend logic to display dynamic content on a webpage.

THEORY:-
1.A full-stack web application consists of both frontend and backend components.
2.HTML (HyperText Markup Language) is used to create the structure of the webpage.
3.CSS (Cascading Style Sheets) is used to style the webpage and improve visual appearance.
4.JavaScript is used to add interactivity and handle events on the client side.
5.The backend processes requests sent from the frontend and returns responses.
6.Communication between frontend and backend occurs using HTTP requests.

In this experiment, JavaScript is used to send a request to the backend, which responds with data that is displayed dynamically on the webpage.

PROCEDURE:-
1.Create an HTML file to define the structure of the webpage.
2.Add a CSS file to style the webpage elements.
3.Write JavaScript code to handle user interaction and fetch data.
4.Set up a backend server to handle requests from the frontend.
5.Connect the frontend JavaScript with the backend using an API endpoint.
6.Run the application on a local server.
7.Verify that data from the backend is successfully displayed on the webpage.

RESULT:-
A basic full-stack web application was successfully developed.
The webpage displayed structured content using HTML, styled layout using CSS, and interactive behavior using JavaScript.
The frontend successfully communicated with the backend and displayed dynamic data on user interaction.

LEARNING OUTCOMES:-

1.After completing this experiment, the student is able to:
2.Understand the roles of HTML, CSS, and JavaScript in web development.
3.Differentiate between frontend and backend components.
4.Create a structured and styled webpage.
